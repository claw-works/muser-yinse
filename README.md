# muser-yinse

English | [简体中文](README.zh-CN.md)

The sound library of [muser](https://github.com/claw-works/muser): modal instruments extracted from recordings (`*.yinse.json`).
An instrument is only partial tables (frequencies, two-stage decays, beating between the strings of a course, left/right,
attack noise, articulations), no audio: tens to a couple of hundred KB.

## Use

```bash
git clone https://github.com/claw-works/muser-yinse.git
export MUSER_YINSE_PATH=/path/to/muser-yinse        # several libraries with the path separator
```

```json
{ "instrument": "yinse:strike/yangqin" }
```

`yinse:<family>/<name>` looks for `instruments/<family>/<name>/<name>.yinse.json` in every library on `MUSER_YINSE_PATH`;
a file path works too. `muser instruments yinse:strike/yangqin` shows its range and articulations.

## Layout

```
instruments/
  strike/            struck: yangqin, piano, bells, marimba ...
  pluck/             plucked: guzheng, pipa, harp, guitar ...
  <family>/<name>/
    <name>.yinse.json  output of muser yinse extract
    meta.json          name, recording source and license, extraction info (below)
    README.md          (optional) recording notes, articulations, comparison
index.json             list of all instruments (generated by scripts/index.py)
```

Only sounds that are struck or plucked and ring away by themselves: the extraction does not suit blown or bowed, held sounds.

## meta.json

```json
{
  "name": "yangqin",
  "zh": "扬琴",
  "family": "strike",
  "description": "402 yangqin, bamboo hammers, dry",
  "source": { "title": "name of the recording set", "url": "https://…", "author": "who recorded it", "license": "CC0-1.0" },
  "extracted": { "muser": "0.6.0", "date": "2026-11-11", "recordings": 39, "compare_db": 2.6 }
}
```

`source.license` is an [SPDX](https://spdx.org/licenses/) id. `compare_db` is the mean spectral difference on the last line of `muser yinse compare`.

## What can go in

- **The recordings' license must allow redistribution and derivatives** (CC0, CC-BY, CC-BY-SA, public domain, or your own
  recordings). Partial tables are derived from the recordings: commercial libraries (Kontakt and others), even free ones,
  cannot be extracted into this repository.
- For CC-BY / CC-BY-SA recordings, credit them in `meta.json` and the README; an instrument from CC-BY-SA recordings is CC-BY-SA too.
- No recordings themselves (`.gitignore` keeps the common audio formats out).
- Run `muser yinse compare` before submitting and put its mean spectral difference in `meta.json`.

How to add an instrument: [CONTRIBUTING.md](CONTRIBUTING.md).
